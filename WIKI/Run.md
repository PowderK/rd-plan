# Installation und erster Start

Diese Seite beschreibt den normalen Start für Endnutzer:innen (ohne Entwickler-Setup).

## 1) Voraussetzungen

- Unterstütztes System: Windows (portable Version)
- Schreibrechte auf den Benutzerordner (für lokale Datenbank und Einstellungen)

## 2) Installation (portable)

1. Lade die aktuelle Version aus den Releases herunter.
2. Speichere die Datei in einen lokalen Ordner (z. B. `C:\RD-Plan\`).
3. Starte die Anwendung per Doppelklick auf die EXE.

![Screenshot-Platzhalter: Download/Datei](screenshots/run-01-download.png)
*Platzhalter: Downloadseite und heruntergeladene EXE-Datei.*

## 3) Erster Start

1. Beim ersten Start wird die lokale Datenablage automatisch vorbereitet.
2. Melde dich mit deiner Personalnummer an (falls Login aktiv).
3. Prüfe, ob du die für dich vorgesehenen Menüpunkte siehst.

![Screenshot-Platzhalter: Login](screenshots/run-02-login.png)
*Platzhalter: Login-Maske mit Personalnummer.*

## 4) Schnellcheck nach dem Start

- Öffnet sich die Ansicht `Einteilung` oder `Dienstplan` korrekt?
- Sind Personal, Fahrzeuge und Werte sichtbar (abhängig von deinen Rechten)?
- Lassen sich Monate/Jahr wechseln?

## 5) Sicheres Arbeiten im Alltag

- App regulär schließen (kein erzwungenes Beenden).
- Bei größeren Änderungen regelmäßig ein Backup durchführen (siehe [Build](Build.md)).
- Vor Importen immer kurz prüfen, ob das richtige Jahr aktiv ist.

## 6) Wenn der Start fehlschlägt

Direkt zu [Troubleshooting](Troubleshooting.md) wechseln.
