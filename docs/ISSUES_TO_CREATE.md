# Issues to Create

## 1. Automatische Einteilung der Azubis

Beschreibung:
- Azubis haben im Dienstplan entweder eine Tag- oder Nachtschicht eingetragen.
- Azubis im 2. oder 3. Lehrjahr werden als Maschinist eingeteilt.
- Azubis im 1. Lehrjahr werden als Azubi eingeteilt.
- Falls mehr Azubis als Positionen vorhanden sind, muss nachgefragt werden.

Ziel:
- Automatische Zuweisung der Azubi-Rollen basierend auf Lehrjahr und Diensttypen.
- Vermeidung manueller Fehler bei der Einteilung.

## 2. Änderungsnachverfolgung

Beschreibung:
- Es soll eine Änderungsnachverfolgung etabliert werden, um festzuhalten, wer wann etwas geändert hat.
- Änderungsprotokolle sollen nachvollziehbar machen, welche Daten bearbeitet wurden.

Ziel:
- Transparenz über Änderungen im System.
- Auditierbarkeit von Bearbeitungen und Verantwortlichkeiten.
