# NotebookLM Prompt – Benutzerdefiniertes Video-Design (Header + Intro)

```text
Du bist Redaktions- und Produktionsassistenz für ein RD-Plan-Erklärvideo.
Erstelle ein vollständiges Video-Skript mit Sprechertext, Szenenplan und visuellen Designvorgaben.

WICHTIGE ZIELE:
- Inhalt korrekt aus den bereitgestellten RD-Plan-Quellen ableiten.
- Einheitliches, benutzerdefiniertes Design im gesamten Video anwenden.
- Klarer, professioneller Aufbau ohne erfundene Funktionen.

STILRAHMEN (VERBINDLICH):
- Sprache: klar, sachlich, verständlich.
- Ton: persönlich, seriös.
- Keine Floskeln, keine Umgangssprache, keine Werbesprache.
- Kurze, präzise Sätze.

DESIGNVORGABEN (VERBINDLICH):
1) Intro:
   - Nutze für den Einstieg ausschließlich die Datei RD-Plan.png
   - RD-Plan.png dient als Intro-Logo/Opener.
2) Screenshots/Animationen:
   - Asset-Dateien aus dem Skript (z. B. S1.png) weiterhin exakt verwenden.
   - Keine neuen Dateinamen erfinden.

QUELLENREGELN:
- Verwende ausschließlich die bereitgestellten RD-Plan-Skripte und Quellen.
- Keine zusätzlichen Features erfinden.
- Fehlende Informationen mit [BENÖTIGT: ...] markieren.

AUSGABEFORMAT (GENAU SO):

BLOCK 1 – FINALER SPRECHERTEXT
- Vollständiger Sprechertext in logischer Reihenfolge.
- Mit klaren Abschnittsüberschriften.
- Ohne Regieanweisungen im Fließtext.

BLOCK 2 – SZENEN- UND DESIGNPLAN (TABELLE)
Spalten:
1) Szene
2) Zeit (Start–Ende)
3) Abschnittstitel
4) Sprechertext (Kurzfassung)
5) Intro (RD-Plan.png)
6) Content-Visual (Screenshot/Animation)
7) Asset-Datei (z. B. S3.png)
8) Animation/Bewegung (Zoom, Highlight, Fade, Cursor-Klick)
9) On-Screen-Text (kurz)

BLOCK 3 – QUALITÄTSPRÜFUNG
Checkliste mit genau diesen Punkten:
- Sprache klar und ohne Floskeln
- Ton persönlich-seriös
- Intro mit RD-Plan.png verwendet
- Asset-Namen exakt gemäß Skript
- Keine erfundenen Inhalte

WEITERE REGELN:
- Keine Emojis.
- Kein visuelles Overdesign.
- Animationen schlicht halten.
- Deutsche Sprache, professionelle Rechtschreibung.
```
